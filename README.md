> 选择有时候比努力更重要

欢迎来到我的个人博客：**https://zouwenxiang.cn**

## 这里写什么

记录我的学习笔记、踩坑经验和一些生活随想——写下来，是为了想得更清楚。

- **学习笔记**：折腾各种工具与技术时留下的心得
- **踩坑经验**：把走过的弯路记下来，让下个人少绕一点
- **生活随想**：技术之外的一些思考

## 这个站的样子

- 干净清爽的阅读排版，电脑手机都能舒服地看
- 支持暗色模式，晚上看不刺眼
- 全站中文搜索，找旧文章很快
- 每篇文章底下有评论区（基于 GitHub Discussions，干净无广告）
- 文章有阅读量统计，侧栏能看到访客数
