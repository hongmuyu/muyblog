## Claude 工作机制笔记：CLAUDE.md / 技能 / 钩子 / 插件 / 代理

## 1. CLAUDE.md
- **定义**：每次会话开始时，Claude 会自动读取的文件，相当于**项目通用的工作指南**。
- **类比**：新员工入职第一天收到的团队规范手册。
- **典型内容示例**：
  - “我们使用`uv` 工具，请执行`uv run python XYZ`，而不是直接`python XYZ`。”
  - “目前移动应用仅供内部测试用户使用，可以随意废弃或修改旧 API 端点。”
  - “当我说‘生产环境’时，请使用那个只读的 Render MCP 界面查询生产日志。”
- **作用**：让 Claude 从一开始就遵循项目约定，避免重复口述相同的背景规则。

## 2. 技能（Skill）
- **定义**：专门解释“如何完成某项任务”的 Markdown 文件，本质是一段**预存的长提示词**。
- **触发方式**：
  - Claude 自动识别并判断何时应用
  - 用户通过斜杠命令显式调用（如`/weekly-report`）
- **作用**：固化重复性任务的要求，减少每次手工描述。
- **示例**：
  - **UI 设计技能**：包含布局偏好、设计系统存放位置等规范。设计新界面时只需引用该技能，无需重复说明。
  - **周度指标报告技能**：包含执行 SQL 查询、解析 CSV、生成 HTML 表格等完整步骤。通过`/weekly-report` 一键触发。

## 3. 钩子（Hook）
- **定义**：一种**程序化确定性机制**：当特定事件 X 触发时，自动执行预先定义好的逻辑。
- **与技能的区别**：技能更灵活、由 Claude 判断是否使用；钩子是硬性、自动触发的。
- **工作原理**：事件 → 自动执行脚本/指令 → 完成指定动作。
- **示例**（移动应用功能完善前）：
  - 事件：Claude 判定任务“已完成”
  - 钩子：自动调用一段 Bash 脚本
  - 脚本行为：通过推送通知 API 向用户的手机和桌面发送“任务完成”提醒
  - **价值**：分配长时间任务后可以离开，手机接收完成通知。

## 4. 插件（Plugins）
- **定义**：为 Claude 添加的第三方扩展，可以是：
  - 一个单一技能
  - 一个包含**多项技能** + **一个 MCP（主控程序）** 的组合包
- **典型组成**：
  - **技能**：具体的操作说明
  - **MCP**：让 Claude 理解如何与外部工具交互，并下达指令（如“截图”“点击元素”）
  - **可执行程序**：如 Playwright（操控无头浏览器）
- **示例**（Playwright 插件）：
  - 内嵌 Playwright 程序（执行浏览器操作）
  - 包含 MCP（让 Claude 知道如何指挥 Playwright 截图、导航等）
  - 包含若干技能（供 Claude 调用上述能力）

## 5. 代理（Agent）
- **定义**：基于 LLM 构建的程序，其核心职能是**实际执行任务**，而不仅仅是对话。
- **模糊性**：这是目前最泛化、最具“流行语”色彩的概念。
- **典型行为**：
  - 编写代码
  - 运行 Bash 命令行
  - 读写文件
  - 发送请求
- **举例**：
  - **Claude Code**：本身就是一种代理程序。
  - **邮件自动回复机器人**：持续监控收件箱，自动回复符合条件的邮件。
- **现实意义**：当今 LLM 的大多数实用场景实质上是“代理”模式，远不止于聊天。

## 总结对比表

| 概念         | 核心性质                  | 触发方式        | 典型用途                  |
| ---------- | --------------------- | ----------- | --------------------- |
| CLAUDE.md  | 静态指南文件                | 会话开始时自动读取   | 设定项目通用规则              |
| 技能（Skill）  | 预存提示词（Markdown）       | 自动识别 / 斜杠命令 | 固化重复性任务的详细说明          |
| 钩子（Hook）   | 程序化确定性脚本              | 特定事件自动触发    | 完成通知、自动化运维等硬性逻辑       |
| 插件（Plugin） | 第三方扩展包（技能 + MCP + 程序） | 用户安装并启用     | 扩展 Claude 的能力（如浏览器控制） |
| 代理（Agent）  | 基于 LLM 的任务执行实体        | 用户启动或事件触发   | 写代码、跑脚本、自动处理外部事务      |
