## 一、基础算法

### 1. 时间复杂度

|复杂度|常见场景|数据规模推测|
|---|---|---|
|O(1)|哈希查询、位运算|任意|
|O(logn)|二分查找、快速幂|任意|
|O(n)|单层遍历|≤ 1e7|
|O(nlogn)|排序、贪心+堆|≤ 1e6|
|O(n²)|双层循环、简单DP|≤ 5000|
|O(n³)|三层循环、Floyd|≤ 500|
|O(2ⁿ)|状态压缩、搜索|≤ 25|
|O(n!)|全排列|≤ 10|

判断循环：

python

for i in range(n):          # O(n)
    pass
for i in range(n):
    for j in range(n):      # O(n²)
        pass

**常见优化**：

- 将 O(n²) 内层用双指针/前缀和优化到 O(n)

- 用快排替代冒泡

- 记忆化搜索减少重复计算

### 2. 递归

递归三要素：终止条件、当前层处理、递归调用。下面以求阶乘为例。

```python
def dfs(n):
    if n == 1:          # 终止条件
        return 1
    return n * dfs(n - 1)  # 当前层逻辑 + 递归

print(dfs(5))  # 120
```

> **注意**：递归深度过大时，用`sys.setrecursionlimit(1000000)` 防止爆栈。

### 5. 双指针

 核心思想：将`O(N²)` 的暴力枚举优化为`O(N)`，**两个指针都只前进不后退**，避免了重复扫描。

- 反向扫描：左右指针从两端向中间移动，常用于有序数组、回文判断等。
- 同向扫描（滑动窗口）：左指针负责删除元素，右指针负责添加元素，`[left, right)` 内的信息就是我们要维护的窗口。

**反向扫描（对撞指针）**

```python
# 判断回文串
S = list(input())
n = len(S)
left, right = 0, n - 1
flag = True
while left <= right:
    if S[left] != S[right]:
        flag = False
        print("N")
        break
    left += 1
    right -= 1
if flag:
    print("Y")
```

**同向扫描（滑动窗口）**

典型问题：最短区间之和 ≥ S
窗口定义：左闭右开`[left, right)`，`tot` 是这个窗口内元素的和。

```python
n, S = map(int, input().split())
a = list(map(int, input().split()))
min_len = n + 1          # 初始化为不可能的大值
left, right = 0, 0       # [left, right)
tot = 0                  # 当前窗口和

while left < n:
    # 不断向右扩展，直到窗口和 >= S
    while right < n and tot < S:
        tot += a[right]
        right += 1
    if tot >= S:         # 窗口满足条件时，更新最短长度
        min_len = min(min_len, right - left)
    # 左端点右移一格，窗口缩小
    tot -= a[left]
    left += 1

print(min_len if min_len != n + 1 else 0)
```

**双指针不回退的理解**：
外层`while left < n` 看似会让`right` 反复被`while` 里移动，但`right` 在每个外层循环中只会向右，整个过程中`right` 最多移动`n` 次，因此总复杂度仍是`O(N)`，不会退化成`O(N²)`。

### 6. 前缀和

一维前缀和可以 O(1) 查询任意区间和。强烈推荐使用 **1‑based 索引**。

```python
# 一维（1-index 强烈推荐）
n = int(input())
a = [0] + list(map(int, input().split()))
pre = [0] * (n + 1)
for i in range(1, n + 1):
    pre[i] = pre[i - 1] + a[i]

# 查询区间 [l, r]
print(pre[r] - pre[l - 1])
```

**二维前缀和**：用于静态子矩阵和查询。

```python
# 二维前缀和
# s[i][j] 表示 (1,1) 到 (i,j) 的和
s = [[0] * (m + 1) for _ in range(n + 1)]
for i in range(1, n + 1):
    for j in range(1, m + 1):
        s[i][j] = s[i-1][j] + s[i][j-1] - s[i-1][j-1] + a[i][j]

# 查询 (x1,y1) 到 (x2,y2) 的和
print(s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] + s[x1-1][y1-1])
```

### 7. 差分

差分是前缀和的逆操作，专门处理**多次区间加减**，最后通过一次前缀和还原。

```python
n, m = map(int, input().split())
a = [0] + list(map(int, input().split()))
b = [0] * (n + 2)    # 多开一位防止越界

# 构造差分数组
for i in range(1, n + 1):
    b[i] = a[i] - a[i - 1]

# 区间修改
for _ in range(m):
    l, r, c = map(int, input().split())
    b[l] += c
    b[r + 1] -= c

# 还原原数组
for i in range(1, n + 1):
    b[i] += b[i - 1]

print(*b[1:n + 1])
```

### 9. 二分查找与二分答案

#### 标准二分查找（精确找值）

```python
l, r = 0, len(a) - 1
while l <= r:
    mid = (l + r) // 2
    if a[mid] == target:
        print(mid)
        break
    elif a[mid] < target:
        l = mid + 1
    else:
        r = mid - 1
```

#### 二分答案（找满足条件的边界）

```python
# 寻找左边界（第一个满足条件的值）
while l < r:
    mid = (l + r) // 2
    if check(mid):
        r = mid
    else:
        l = mid + 1

# 寻找右边界（最后一个满足条件的值）
while l < r:
    mid = (l + r + 1) // 2
    if check(mid):
        l = mid
    else:
        r = mid - 1
```

> **核心要求**：`check` 函数必须具有单调性（前假后真，或前真后假）。
> **浮点二分**：循环`for _ in range(100):` 即可保证精度。

## 二、搜索

### 1. DFS（深度优先搜索）

以下是使用 DFS 统计无向图中连通块数量的模板。

```python
import sys
sys.setrecursionlimit(10**6)

n, m = map(int, input().split())
g = [[] for _ in range(n + 1)]
vis = [False] * (n + 1)

for _ in range(m):
    u, v = map(int, input().split())
    g[u].append(v)
    g[v].append(u)  # 无向图

def dfs(x):
    vis[x] = True
    # 处理当前节点（如输出）
    for y in g[x]:
        if not vis[y]:
            dfs(y)

# 连通块遍历
cnt = 0
for i in range(1, n + 1):
    if not vis[i]:
        cnt += 1
        dfs(i)
print(cnt)
```

```python
def backtrack():
    if len(path) == n:
        print(*path)
        return
    for i in range(n):
        if not used[i]:

            path.append(a[i])
            backtrack()
            path.pop()
            used[i] = False
```

### 4. BFS（广度优先搜索）

BFS 天然适合求**无权图最短路**（步数最少）。下面是从起点 1 到终点 n 的最短距离。

```python
from collections import deque

n, m = map(int, input().split())
g = [[] for _ in range(n + 1)]
for _ in range(m):
    u, v = map(int, input().split())
    g[u].append(v)

start, target = 1, n
q = deque([start])
dist = [-1] * (n + 1)
dist[start] = 0

while q:
    u = q.popleft()
    for v in g[u]:
        if dist[v] == -1:
            dist[v] = dist[u] + 1
            q.append(v)

print(dist[target])  # 最短距离
```

## 三、动态规划

> DP = 状态定义 + 状态转移 + 初始化 + 遍历顺序
> 把大问题拆成重叠子问题，用表格记录下来。

### 1. LIS 最长上升子序列

**状态**：`dp[i]` 表示以`a[i]` 结尾的 LIS 长度。
**转移**：`dp[i] = max(dp[j] + 1) for j < i and a[j] < a[i]`

```python
n = int(input())
a = [0] + list(map(int, input().split()))
dp = [1] * (n + 1)
for i in range(1, n + 1):
    for j in range(1, i):
        if a[j] < a[i]:
            dp[i] = max(dp[i], dp[j] + 1)
print(max(dp))

# 贪心+二分 O(n log n) 版本
import bisect
tails = []
for x in a[1:]:
    idx = bisect.bisect_left(tails, x)
    if idx == len(tails):
        tails.append(x)
    else:
        tails[idx] = x
print(len(tails))
```

---

### 2. LCS 最长公共子序列

**状态**：`dp[i][j]` 表示`a[1..i]` 和`b[1..j]` 的 LCS 长度。
**转移**：相等时加一，否则继承上方或左方的最大值。

```python
n, m = map(int, input().split())
a = [0] + list(input().split())
b = [0] + list(input().split())
dp = [[0] * (m + 1) for _ in range(n + 1)]
for i in range(1, n + 1):
    for j in range(1, m + 1):
        if a[i] == b[j]:
            dp[i][j] = dp[i - 1][j - 1] + 1
        else:
            dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
print(dp[n][m])
```

### 5. 多重背包（二进制优化）

每种物品有`s` 件，拆成 2^k 组合，转化为 0/1 背包。

```python
n, m = map(int, input().split())
goods = []
for _ in range(n):
    w, v, s = map(int, input().split())
    k = 1
    while s >= k:
        goods.append((w * k, v * k))
        s -= k
        k <<= 1
    if s > 0:
        goods.append((w * s, v * s))

dp = [0] * (m + 1)
for w, v in goods:
    for j in range(m, w - 1, -1):
        dp[j] = max(dp[j], dp[j - w] + v)
print(dp[m])
```

### 6. 区间 DP

典型问题：石子合并（相邻合并，求最小代价）。
**状态**：`dp[l][r]` 表示合并区间`[l, r]` 的最小代价。
**转移**：枚举分割点`k`，`dp[l][r] = min(dp[l][k] + dp[k+1][r]) + sum(l..r)`。

```python
n = int(input())
a = [0] + list(map(int, input().split()))
pre = [0] * (n + 1)
for i in range(1, n + 1):
    pre[i] = pre[i - 1] + a[i]

dp = [[0] * (n + 1) for _ in range(n + 1)]
for length in range(2, n + 1):
    for l in range(1, n - length + 2):
        r = l + length - 1
        dp[l][r] = float('inf')
        for k in range(l, r):
            dp[l][r] = min(dp[l][r], dp[l][k] + dp[k + 1][r])
        dp[l][r] += pre[r] - pre[l - 1]
print(dp[1][n])
```

## 四、字符串

### 1. KMP

快速在文本串中查找模式串的所有出现位置。核心是`next` 数组（前缀函数）。

```python
def get_next(p):
    m = len(p)
    ne = [0] * m
    j = 0
    for i in range(1, m):
        while j and p[i] != p[j]:
            j = ne[j - 1]
        if p[i] == p[j]:
            j += 1
        ne[i] = j
    return ne

def kmp(s, p):
    n, m = len(s), len(p)
    ne = get_next(p)
    j = 0
    res = []
    for i in range(n):
        while j and s[i] != p[j]:
            j = ne[j - 1]
        if s[i] == p[j]:
            j += 1
        if j == m:
            res.append(i - m + 1)
            j = ne[j - 1]
    return res

# 示例：输出所有匹配起始位置
print(kmp("abababac", "aba"))
```

### 2. 字符串哈希

将字符串映射为整数，便于 O(1) 比较子串是否相等。通常使用进制哈希（如 131 进制，模 2^64 自动溢出）。

```python
s = ' ' + input().strip()
n = len(s) - 1
P, MOD = 131, 2**64  # 也可显式取模，或利用 Python 大整数自动截断（但建议加模数）

h = [0] * (n + 1)
p = [1] * (n + 1)
for i in range(1, n + 1):
    h[i] = (h[i - 1] * P + ord(s[i])) % MOD
    p[i] = (p[i - 1] * P) % MOD

def get_hash(l, r):
    return (h[r] - h[l - 1] * p[r - l + 1]) % MOD

# 判断两个子串是否相等
print(get_hash(1, 3) == get_hash(4, 6))
```

### 3. Manacher（最长回文子串 O(n)）

线性时间求最长回文子串。

```python
def manacher(s):
    t = '^#' + '#'.join(s) + '#$'
    n = len(t)
    p = [0] * n
    c = r = 0
    for i in range(1, n - 1):
        p[i] = min(r - i, p[2 * c - i]) if r > i else 0
        while t[i + p[i] + 1] == t[i - p[i] - 1]:
            p[i] += 1
        if i + p[i] > r:
            c, r = i, i + p[i]
    max_len = max(p)
    center = p.index(max_len)
    start = (center - max_len) // 2
    return s[start:start + max_len]

print(manacher("babad"))
```

### 4. Trie 树（字典树）

用于高效存储和查询字符串集合，支持前缀匹配和词频统计。

```python
class TrieNode:
    __slots__ = ['son', 'cnt']
    def __init__(self):
        self.son = {}
        self.cnt = 0  # 结尾次数

class Trie:
    def __init__(self):
        self.root = TrieNode()
    def insert(self, word):
        cur = self.root
        for ch in word:
            if ch not in cur.son:
                cur.son[ch] = TrieNode()
            cur = cur.son[ch]
        cur.cnt += 1
    def query(self, word):   # 完整单词出现次数
        cur = self.root
        for ch in word:
            if ch not in cur.son:
                return 0
            cur = cur.son[ch]
        return cur.cnt
        
t = Trie()
# 插入单词
t.insert("apple")
t.insert("app")
t.insert("apple")
# 查询完整单词出现次数
print(t.query("apple"))   # 2
print(t.query("app"))     # 1
print(t.query("ap"))      # 0
```

```python
import heapq

heapq.heapify(a)
ans = 0

    heapq.heappush(a, x + y)
```

### 2. 拓扑排序（BFS）

```python
from collections import deque
n, m = map(int, input().split())

indeg = [0] * (n + 1)
for _ in range(m):
    u, v = map(int, input().split())

    indeg[v] += 1

q = deque([i for i in range(1, n + 1) if indeg[i] == 0])
res = []
while q:
    u = q.popleft()
    res.append(u)
    for v in g[u]:
        indeg[v] -= 1
        if indeg[v] == 0:
            q.append(v)

if len(res) == n:
    print(*res)
else:
    print("有环")
```

### 3. 最短路

#### Dijkstra（正权，堆优化 O((n+m)log n)）

```python
import heapq
inf = 10**18
n, m = map(int, input().split())
g = [[] for _ in range(n + 1)]
for _ in range(m):
    u, v, w = map(int, input().split())
    g[u].append((v, w))

dist = [inf] * (n + 1)
dist[1] = 0
pq = [(0, 1)]
while pq:
    d, u = heapq.heappop(pq)
    if d != dist[u]:
        continue
    for v, w in g[u]:
        if dist[v] > dist[u] + w:
            dist[v] = dist[u] + w
            heapq.heappush(pq, (dist[v], v))

print(dist[n] if dist[n] != inf else -1)
```

#### Floyd（全源最短路 O(n³)）

```python
inf = 10**18
for k in range(1, n + 1):
    for i in range(1, n + 1):
        for j in range(1, n + 1):
            if g[i][k] + g[k][j] < g[i][j]:
                g[i][j] = g[i][k] + g[k][j]
```

#### SPFA（可负权，慎用，用于判负环）

```python
from collections import deque
inf = 10**18
dist = [inf] * (n + 1)
dist[1] = 0
inq = [False] * (n + 1)
cnt = [0] * (n + 1)  # 判负环
q = deque([1])
inq[1] = True
while q:
    u = q.popleft()
    inq[u] = False
    for v, w in g[u]:
        if dist[v] > dist[u] + w:
            dist[v] = dist[u] + w
            cnt[v] = cnt[u] + 1
            if cnt[v] >= n:
                print("负环")
                exit()
            if not inq[v]:
                q.append(v)
                inq[v] = True
```

### 4. 并查集

路径压缩 + 按秩合并，用于动态连通性判断。

```python
class DSU:
    def __init__(self, n):
        self.p = list(range(n + 1))
        self.sz = [1] * (n + 1)
    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb: return False
        if self.sz[ra] < self.sz[rb]:
            ra, rb = rb, ra
        self.p[rb] = ra
        self.sz[ra] += self.sz[rb]
        return True

dsu = DSU(5)       # 初始化 1~5 五个元素
dsu.union(1, 2)
dsu.union(2, 3)
print(dsu.find(1)) # 与 find(3) 相同
print(dsu.find(3)) # 与 find(1) 相同
print(dsu.union(1, 3))  # False，已经连通
print(dsu.union(4, 5))  # True
```

```python
def qpow(a, b, mod):
    res = 1
    while b:
        if b & 1: res = res * a % mod
        a = a * a % mod
        b >>= 1
    return res
```

## 九、数据结构

### 1. 树状数组（单点修改，区间查询）

支持单点加、前缀和查询，复杂度 O(log n)。

```python
class BIT:
    def __init__(self, n):
        self.n = n
        self.tree = [0] * (n + 1)
    def lowbit(self, x):
        return x & -x
    def add(self, idx, delta):
        while idx <= self.n:
            self.tree[idx] += delta
            idx += self.lowbit(idx)
    def query(self, idx):
        res = 0
        while idx > 0:
            res += self.tree[idx]
            idx -= self.lowbit(idx)
        return res
    def range_sum(self, l, r):
        return self.query(r) - self.query(l - 1)

bit = BIT(10)
bit.add(3, 5)      # 在位置 3 加 5
bit.add(5, 2)      # 在位置 5 加 2
print(bit.query(4))   # 前缀和 [1..4] → 5
print(bit.range_sum(3, 5))  # 区间和 [3..5] → 5+2=7
```

### 2. 线段树（区间修改，区间查询）

支持懒标记的区间加、区间求和。

```python
class SegTree:
    def __init__(self, n, a):
        self.n = n
        self.tree = [0] * (4 * n)
        self.lazy = [0] * (4 * n)
        self.build(1, 1, n, a)
    def build(self, p, l, r, a):
        if l == r:
            self.tree[p] = a[l]
            return
        mid = (l + r) // 2
        self.build(p<<1, l, mid, a)
        self.build(p<<1|1, mid+1, r, a)
        self.tree[p] = self.tree[p<<1] + self.tree[p<<1|1]
    def push_down(self, p, l, r):
        if self.lazy[p]:
            mid = (l + r) // 2
            self.tree[p<<1] += self.lazy[p] * (mid - l + 1)
            self.tree[p<<1|1] += self.lazy[p] * (r - mid)
            self.lazy[p<<1] += self.lazy[p]
            self.lazy[p<<1|1] += self.lazy[p]
            self.lazy[p] = 0
    def update(self, p, l, r, ql, qr, val):
        if ql <= l and r <= qr:
            self.tree[p] += val * (r - l + 1)
            self.lazy[p] += val
            return
        self.push_down(p, l, r)
        mid = (l + r) // 2
        if ql <= mid: self.update(p<<1, l, mid, ql, qr, val)
        if qr > mid:  self.update(p<<1|1, mid+1, r, ql, qr, val)
        self.tree[p] = self.tree[p<<1] + self.tree[p<<1|1]
    def query(self, p, l, r, ql, qr):
        if ql <= l and r <= qr:
            return self.tree[p]
        self.push_down(p, l, r)
        mid = (l + r) // 2
        res = 0
        if ql <= mid: res += self.query(p<<1, l, mid, ql, qr)
        if qr > mid:  res += self.query(p<<1|1, mid+1, r, ql, qr)
        return res

# 原始数组（1‑based）
a = [0, 1, 2, 3, 4, 5]   # a[1]=1, a[2]=2, ... a[5]=5
seg = SegTree(5, a)

seg.update(1, 1, 5, 2, 4, 10)   # 区间 [2,4] 每个元素加 10
print(seg.query(1, 1, 5, 1, 5)) # 查询整个区间和 → (1) + (2+10)+(3+10)+(4+10)+5 = 1+12+13+14+5=45
```

### 3. ST 表（静态区间最值查询，O(1)）

预处理 O(n log n)，查询 O(1)，不支持修改。

```python
import math
class SparseTable:
    def __init__(self, a):
        self.n = len(a)
        K = math.floor(math.log2(self.n)) + 1
        self.st = [[0] * K for _ in range(self.n)]
        for i in range(self.n):
            self.st[i][0] = a[i]
        j = 1
        while (1 << j) <= self.n:
            i = 0
            while i + (1 << j) <= self.n:
                self.st[i][j] = max(self.st[i][j-1], self.st[i + (1 << (j-1))][j-1])
                i += 1
            j += 1
    def query(self, l, r):   # [l, r] 闭区间
        k = r - l + 1
        k = k.bit_length() - 1
        return max(self.st[l][k], self.st[r - (1 << k) + 1][k])

arr = [3, 1, 4, 1, 5, 9, 2]
st = SparseTable(arr)            # 下标从 0 开始
print(st.query(1, 4))            # 区间 [1,4] 最大值 → max(1,4,1,5)=5
print(st.query(0, 6))            # 整个数组最大值 → 9
```
