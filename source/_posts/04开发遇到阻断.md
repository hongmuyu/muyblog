开发过程中遇到发布阻断时，可以用下面这套提示词流程，让 AI 按 P0/P1/P2 拆分修复任务、逐项完成并做阶段评审。

## 1. 重新生成发布报告

```text
重新生成 RELEASE_REPORT.md
```

## 2. 拆分修复任务

```text
读取：RELEASE_REPORT.md

识别：Blocking Issues

按照：P0、P1、P2 拆分修复任务

生成：RELEASE_TASKS.md
```

## 3. 按优先级逐项修复

```text
读取：RELEASE_TASKS.md

选择：最高优先级 P0 且依赖满足的任务
约束：一次只允许完成一个任务

完成：
1. 实现代码
2. 编写测试
3. 更新文档
4. 更新 RELEASE_TASKS.md

完成后停止。
```

## 4. 阶段评审

```text
读取：代码、FINAL_TECH_SPEC.md、RELEASE_TASKS.md

任务：评审当前实现

检查：
1. 是否满足 TECH_SPEC
2. 是否修复对应 Blocking Issue
3. 是否引入新风险

生成：PHASE_REVIEW.md
```

## 5. 回到发布报告

```text
重新生成 RELEASE_REPORT.md
```
