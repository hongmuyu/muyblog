# 第一次投实习：从学完 Agent 开发到简历复盘

## 前言

第一次投实习，是在我刚刚学完 Agent 开发这条路线的时候。

那段时间恰巧看到朋友拿到了实习，于是我也想着先把简历完善一下，投投看，试试水。

现在回头看，这次投递更像是一次提前暴露问题的复盘：简历、方向、时间点、技术栈，都需要重新梳理。

## 第一份简历

第一份简历大概是在这种背景下赶出来的：

> ![](/images/pasted-image-1793431284689.png)

当时想法很简单：先把简历做出来，投出去看看反馈。

## 投递反馈：几天没人要

投了几天，基本没什么回应。

一方面可能是十月份这个时间点确实不太好找；另一方面，我朋友是暑假找到的，时间窗口也不一样。

所以这次没消息，倒也不完全意外。只是第一次投实习就遇到冷启动，还是有点受打击。

## 一个有点 drama 的插曲

比较戏剧性的是，后来有卖实习指导、简历改写的人加我，说我的联系方式被卖了。

一开始觉得挺离谱的，不过冷静下来想了想，对方倒是间接给了我一些思路：

- Python 后端和 Web 开发，我还没有深入学；
- 传统后端相关的东西，也需要补一补；
- 只靠 Agent 开发这一条线，简历和岗位匹配度可能还不够。

这么一想，也算是坏事里捡到一点有用信息。

## 复盘与调整

这次投递让我意识到，找实习不是“学完一条路线 → 改简历 → 投出去”这么线性。

至少有几个问题需要提前处理：

1. **时间点**：十月份可能不是最友好的窗口，暑假前后机会可能更多；
2. **技术栈**：Agent 开发之外，Python 后端、Web 开发、传统后端基础都要补；
3. **简历匹配度**：简历需要针对岗位方向调整，而不是一份简历投所有；
4. **心态**：第一次投没有反馈很正常，先把它当成一次市场测试。

好事多磨吧。

## 接下来的计划

大三上这个学期课也挺多，虽然我经常不去上（bushi），但真挂了也很麻烦。

所以接下来的节奏大概是：

- 先把学校课程稳住，避免挂科；
- 继续补 Python 后端、Web 开发和传统后端基础；
- 完善简历，等到寒假之前，尽量在 12 月份左右再投一轮实习；
- 把这次投递当成一次预演，而不是最终结果。

## 结语

第一次投实习没什么回音，多少有点遗憾，但也不算白投。

至少它让我提前看到了自己的短板，也让我知道下一步该补什么。

先沉下来准备，12 月左右再试一次。
