1.`feature-dev`：引导式功能开发工作流。内置三个代理（Agent）：代码探索者（`code-explorer`）、代码架构师（`code-architect`）和代码评审员（`code-reviewer`）。其中的“架构师”代理正是该插件的独到之处——它能在任何代码编写之前，就对那些过度设计的方案提出质疑并予以纠正。

2.`code-review`：对当前分支运行`/code-review` 命令。五个并行运行的 Sonnet 代理将协同检查代码中的 Bug、是否符合`CLAUDE.md` 规范、历史上下文、拉取请求（PR）的历史记录以及过时的注释。置信度阈值默认为 80，您可以在`commands/code-review.md` 文件中进行配置。添加`--comment` 参数，即可将评审意见作为行内注释直接发布到对应的拉取请求中。

3.`commit-commands`：以斜杠命令（Slash Commands）形式提供的 Git 工作流基础工具集。它负责处理提交信息（Commit Message）的格式化、分支规范管理，以及那些若每次都需手动输入便会打断工作流的琐碎重复性任务。

4.`frontend-design`：专为前端开发工作自动触发的技能模块。它强制执行关于排版、配色、间距和动画的设计规范，从而避免模型简单地套用通用的 Tailwind 默认样式。即使您仅偶尔从事前端工作，该插件也依然值得安装。

5.`claude-md-management`：用于审计和维护代码仓库中`CLAUDE.md` 文件的工具。它能识别出过时的规则、重复的指导说明，以及那些 Claude 正在默默忽略的指令。这是大多数团队都迫切需要，却往往忽略安装的插件。

6.`security-guidance`：一个“会话启动钩子”（SessionStart hook），当您编辑的文件匹配到高风险模式（如命令注入路径、跨站脚本 [XSS] 攻击的接收点、不安全的序列化操作等）时，它会自动注入安全警告。该钩子在每次会话开始时都会运行，完全免费，且能捕获到常规代码评审中可能遗漏的安全隐患。

7.`code-simplifier`：针对近期修改的代码执行重构优化。在保留原有功能和命名规范的前提下，移除冗余的分支代码、多余的防御性判断（Guards），以及因意外引入的复杂性。建议将其与`code-review` 插件搭配使用，并在代码推送（Push）前同时运行这两个工具。

8.`plugin-dev`：用于构建自定义插件的开发工具包。通过`/plugin-dev:create-plugin` 命令，您可以体验一个包含八个阶段的引导式工作流；此外，该插件还提供了七项辅助技能，涵盖了钩子（Hooks）、模型上下文协议（Model Context Protocol）集成、插件结构设计、配置设置、命令定义、代理（Agent）开发以及技能开发等方方面面。当现有插件无法满足您的特定需求时，这是一个理想的起点。

9. pyright-lsp 与 typescript-lsp。这两款语言服务器插件将 Pyright 和 TypeScript 编译器集成到了 Claude Code 中。借助它们，Claude 能够支持“跳转到定义”、“查找引用”等功能，并在代码编辑后即时提示类型错误。由于您只需根据自身技术栈选择安装其中一款，因此这两者在此处合并计为一项。

10. superpowers。这是 Anthropic 官方推出的一款插件，专为头脑风暴、子代理驱动开发、调试工作流、测试驱动开发以及技能编写等场景而设计。它是目前功能最为全面的官方“全能型”插件；如果您尚未建立属于自己的相关工作模式，强烈建议保持该插件的启用状态。

11.`playwright` —— 浏览器自动化与测试工具。Claude 可以通过该插件启动浏览器、浏览网页、截屏、填写表单，甚至运行端到端（E2E）测试。如果你正在构建任何包含前端界面的项目，这个插件将非常有用。

12.`pr-review-toolkit` —— 功能类似于`code-review`，但更专注于 PR 的具体工作流。它可以自动生成审查评论、建议代码修改方案，并检查 PR 中常见的各类问题。

13. context7 —— 文档查阅功能。Claude 可以获取库的最新文档，而无需仅依赖其自身的训练数据。当你处理迭代速度极快的框架时，此功能尤为实用。

14. GitHub —— 代码库深度理解功能。 Claude 可以直接访问和分析 GitHub 代码库，无需手动复制代码。它能够浏览项目结构、分析 PR 和 Commit、进行代码审查，并结合整个代码库上下文生成修复方案，特别适用于大型项目开发与开源协作。

15. Memory —— 持久化项目记忆功能。Claude 可以长期保存项目相关信息，包括架构决策、编码规范、工作流规则、项目结构以及当前任务状态，从而在后续会话中持续复用这些上下文，尤其适合大型代码库维护、团队协作和长期项目开发。
