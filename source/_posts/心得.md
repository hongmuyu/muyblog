遇到“求最大值的最小值”问题，我们首先应该想到**二分答案**。
check()函数，用来判断当前的二分答案是否满足条件，满足条件就缩小二分答案，不满足则放大
- 遇到“求满足条件的最小/最大值”时，用二分答案 + 贪心验证，把求解问题降维成判定问题。

- 区间问题的通用套路：按左端点排序 + 游标按需入堆 + 堆顶贪心（如最小右端点）。

- 外层循环管状态推进，内层 while 控制游标入堆，游标不回退，总复杂度 O(N log N) 而非 O(N²)。

- 遇到精度风险时，把坐标或长度放大两倍转成整数运算，彻底消除浮点误差，最后再还原。

- Python 列表乘法 [1,2]*2 是重复拼接，不是数值翻倍；数值翻倍需手动遍历。

- 堆的正确用法：heappush 已维护堆序，不要在 push 后调用 heapify，否则 O(N) 劣化效率。

- 组合技：二分 + 贪心 + 堆 + 双指针，是区间覆盖/任务调度/动态最优化类题目的万能钥匙。
```
import heapq  
n=int(input())  
Query=[]  
#记录每个区间  
for _ in range(n):  
    Query.append(list(map(int,input().split())))  
#区间按照左端点排序  
Query.sort(key=lambda x:x[0])  
#避免浮点数精度问题  
for i in range(n):  
    #放大两倍  
    Query[i][0]*=2  
    Query[i][1]*=2  
#判断当前最大位移x是否满足要求  
def check(x):  
    p=0 #指针初始化  
    prio=[] #小根堆  
    idx=0 #游标  
    #遍历所有区间  
    while p<20000:  
        while idx<len(Query):  
            l = Query[idx][0]  # 当前区间的左端点  
            r = Query[idx][1]  # 当前区间的右端点  
            if l - x <= p:  
                heapq.heappush(prio, (r, l))  # 存储 (右端点, 左端点)  
                idx += 1  # 移动游标  
            else: break #不满足l - x <= p就退出循环，停止移动idx  
        # 断档判断  
        if not prio:  
            return False  
        else:  
            # 弹出堆顶（最小 r 的区间）  
            r_min, l_min = heapq.heappop(prio)  
            # 移动区间  
            left = min(p, l_min + x)  # 新的左端点  
            right = left + r_min - l_min  # 新的右端点:左端点+区间长度  
            # 更新p  
            p = max(p, right)  
    return True  
#二分答案  
L,R=0,20000  
ans=0  
while L<=R:  
    mid=(L+R)//2  
    if check(mid):  
        R=mid-1 #满足就缩小  
        ans=mid  
    else:  
        L=mid+1 #不满足就放大  
#分奇偶  
print(ans//2 if ans%2==0 else f"{ans/2:.1f}")
```

```
#求一个排列的后 m 个字典序排列
def next(a,n):  
    i=n-2 #倒数第二个开始找  
    while i>=0:  
        #找第一个升序  
        if a[i]<a[i+1]:  
            break  
        i-=1  
    # 边界处理 （严格降序） N,N-1,N-2,...,1    if i == -1:  
        a[0:] = reversed(a[0:])  
        return a  
    j=n-1  
    while j>i:  
        if a[j]>a[i]: #降序里面找第一个比i大的  
            a[i],a[j]=a[j],a[i] #交换位置  
            a[i+1:] = reversed(a[i+1:]) #降序部分变为升序  
            break  
        j-=1  
    return a
```

• 解决二维坐标的矩形覆盖或区间框选问题，通用策略是“降维打击”：先对一个维度进行遍历锁定（框定 X 轴），再在提取出的子集中处理另一个维度（在 Y 轴滑动）。
• 排序是处理一切区间极值、距离跨度问题的前提，它可以将抽象的空间距离转化为数组元素间的数学差值。
• **寻找最优区间时**，千万不能把区间的某一端固定死（例如总是从第一个元素开始计算差值），必须允许区间的上下界都能自由滑动，否则必定会遗漏半空中的最优解。
• 编写滑动窗口时优先使用标准范式：右指针主动通过 for 循环向右探索，一旦破坏条件，左指针立刻在 while 循环中被动收缩，直到重新合法后再记录答案，这样能保证每一步记录的都是有效状态。
• 在错误分支中乱更新最值是极其常见的易错点，时刻牢记：只有在窗口状态完全合法时，才能去更新全局的 max 或 min。
```
ans = 0 
for x in range(N):
    # 截取横坐标符合条件的怪物
    path = []
    for j in range(x, N):
        if monsters[j][0] - monsters[x][0] <= A:
            path.append(monsters[j])
        else:
            break
            
    # 按纵坐标排序
    path.sort(key=lambda x: x[1])
    
    # 纵坐标滑动窗口的标准写法
    left_y = 0
    layer_max = 0
    for right_y in range(len(path)):
        # 如果当前窗口不合法，持续将左边界向上提
        while path[right_y][1] - path[left_y][1] > B:
            left_y += 1
        # 此时窗口一定合法，直接更新最大值
        layer_max = max(layer_max, right_y - left_y + 1)
        
    ans = max(ans, layer_max)
```

• 二维问题降维打击策略：面对多维或多边界变量时，暴力枚举极易超时，核心思想是“用循环钉死其中几个维度（如上下边界）”，将原问题平替为经典的一维问题（如一维连续子数组求和）。
• 滑动窗口一主一从范式：窗口滑动的标准写法是“右指针通过 for 循环主动向右探索，左指针在 while 循环内因条件不满足而被动收缩”，切忌让两个指针在平级的 if-else 中互相干扰。
• 连续子数组的计数公式：在满足单调性的滑动窗口中，一旦确定了合法的区间 [left, right]，以 right 为右端点的所有合法子数组数量恒等于 right - left + 1，这是无需逐个遍历即可实现 O(1) 累加的黄金公式。
• 嵌套循环边界的依赖性：在枚举区间或组合时，内层循环的起点往往依赖外层变量（如底边坐标不能小于顶边坐标），这是二维遍历极容易翻车的隐蔽逻辑错漏。
• 二维前缀和与滑动窗口的结合：二维前缀和负责 O(1) 提取数据，滑动窗口负责 O(M) 遍历组合，两者结合能将 O(N²M²) 的暴力算法平滑降维至 O(N²M) 的极速时间复杂度。
• 时空复杂度的动态权衡：固定行枚举列的复杂度为 O(N²M)，如果遇到行数极多但列数极少的矩阵，只需调换思路，固定左右边界、在行上滑动窗口，即可将复杂度转为 O(M²N) 实现灵活避坑。
```
ans = 0  # 全局答案
for top in range(1, n + 1):
    for bottom in range(top, n + 1):  # 优化：下边界从上边界开始枚举，避免无效计算
        # 固定上下边界
        left = 1
        for right in range(1, m + 1):
            tot = s[bottom][right] - s[top - 1][right] - s[bottom][left - 1] + s[top - 1][left - 1]
            # 直到 tot <= k 才出循环
            while left <= right and tot > k:
                left += 1
                tot = s[bottom][right] - s[top - 1][right] - s[bottom][left - 1] + s[top - 1][left - 1]
            ans += right - left + 1
print(ans)
```

• 乘法原理解决组合计数：将一个大的区间划分问题，巧妙转化为求解多个相邻“缓冲带”内分割点的独立事件，利用乘法原理累乘各间隙的方案数即可轻松破解。
• 边界与特殊情况优先排查：对于计数问题，开篇即对无解（总数为0或无法整除）进行阻断，在核心逻辑中重点审视极小值（如 K=1K=1K=1）是否兼容，这是保证代码鲁棒性的标准动作。
• 状态更新顺序的防覆盖防线：在一次遍历中同时结算上一轮状态并更新本轮状态时，必须严格遵守“先结算差值/结果，后更新基准指针”的顺序，以防关键锚点被提前抹除。
• 模运算的及时渗透：题目出现“答案可能很大”时，不仅要在最后取模，务必在每一次累乘迭代的当下直接取模，以此规避 Python 超大整数底层运算带来的隐性时间损耗。
• 数据结构的降维打击：在进行海量的高频匹配检查时，将 List 升级为 Set，可瞬间将单次查找的 O(M)O(M)O(M) 复杂度降至 O(1)O(1)O(1)，是性价比极高的常数级优化技巧。
• 周期判定与计数器同频：在处理“固定数量成组”的逻辑时，单调递增的计数器配合取余运算（如`cnt % K == 0` 或`(cnt - 1) % K == 0`）能最精确、最优雅地定位到周期的头尾，避免了复杂的嵌套状态机。

```python
n = int(input())
a = []
for i in range(n):
    row = list(map(int, input().split()))
    a.append(row)

# 校验最小V：若A//v > B，说明v太小
def check_min(a, v):
    for A, B in a:
        if A // v > B:
            return False
    return True

# 校验最大V：若A//v < B，说明v太大
def check_max(a, v):
    for A, B in a:
        if A // v < B:
            return False
    return True

# 找最小值
left_min, right_min = 1, 10**9
while left_min < right_min:
    mid = (left_min + right_min) // 2
    if check_min(a, mid):
        right_min = mid
    else:
        left_min = mid + 1

# 找最大值
left_max, right_max = 1, 10**9
while left_max < right_max:
    mid = (left_max + right_max + 1) // 2
    if check_max(a, mid):
        left_max = mid
    else:
        right_max = mid - 1

print(left_min, left_max)
```

• 二分查找的本质不是找“相等”，而是找“边界”，必须用大于/小于号构造出一半True、一半False的单调性悬崖
• 求最小值（左边界）时，条件满足则区间往左缩（right=mid），此时mid正常向下取整
• 求最大值（右边界）时，条件满足则区间往右缩（left=mid），此时mid必须向上取整（加1再除2），否则会陷入死循环
• 二分的初始范围应秉持“宁大勿漏”原则，上限直接给到数据范围极值（如10的9次方），对数级复杂度下这几乎不增加耗时
• 涉及除法运算的二分，左边界绝对不能为0，必须结合物理意义设为1以防引发除零异常
• 标准二分模板在while left < right结束时，指针必然相遇在正确答案上，无需额外使用变量来记录每一次的mid

```
#   使用 combinations(iterable, r)，元素按输入顺序，不重复
for c in combinations([1, 2, 3, 4], 2):
```

```
#   使用 product(*iterables, repeat=1)，可以指定重复次数
for i, j in product(range(2), range(3)):
    print(i, j)  # 0 0, 0 1, 0 2, 1 0, 1 1, 1 2
```

```
t = int(input())

for _ in range(t):

    if k == 1:

```
删除了冗余的`maxvalue, minvalue = 0, 0` 初始赋值，因为`if-else` 分支已经覆盖了所有情况；移除了`print` 函数中多余的`sep=' '`，因为空格本身就是`print` 多个参数时的默认分隔符。代码整体显得更加干净整洁。

以下是在这道题中可以收获的经验性知识：

• 按位或运算具有“单调不减”的性质，即参与或运算的数越多，结果的二进制 1 只会增多或保持不变，值永远不会变小
• 求位运算最大值时，寻找互补的二进制掩码是核心策略。对于任意整数 n，选取 n 及其最高位以下的“全 1 数”（即 2^m−1）进行或运算，即可凑满所有位，得出理论最大值
• 求多数字按位或最小值时，本质是找“最少需要多少个二进制位，能组合出至少 k 个非零数”。因为 p 个位能组合出 2^p−1个非零数，所以该问题可完美转化为求 2^p−1≥k 的最小 p
• Python 的`int.bit_length()` 是处理二进制极值问题的神器，能够 O(1)时间快速获取二进制位数，省去了复杂的位移枚举或 math 库调用
• 遇到 N≤10^9数据范围的位运算极值题目，通常不存在 O(N)的遍历解法，必定存在某种 O(1)的位运算公式或规律推导
