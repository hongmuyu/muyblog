> **一个会陪你一起崩溃的 DDL 模拟器**

将赶 DDL 的崩溃感游戏化，可视化你的精神状态，陪你抽象且快乐地活过这周。

**版本：v2.2（v35）** · 纯本地 SQLite，100% 离线，数据不出设备。

---

## ✨ 功能亮点

|模块|功能描述|
|---|---|
|💀 **DDL 倒计时**|实时血条 + 危险等级（安全→注意→危险→红温→濒死），支持`5-20`、`明天` 等智能日期解析|
|🧠 **精神状态系统**|生命值、理智值、睡眠债、功德值、发疯浓度五维数值，实时根据行为数据计算|
|⏱ **摸鱼计时器**|学习 / 摸鱼双模式计时；停止后自动累加；App 被杀后差值恢复；支持跨天拆分|
|📸 **生存日报卡片**|拍立得风格每日快照，可保存相册 / 分享；保留历史记录（动态生成，不存图片）|
|💬 **自定义语录**|10 条内置幽默语录 + 用户自定义；支持 JSON 导入 / 导出；首页随机展示|
|🏆 **成就系统**|阴间作息、极限施法、工位流浪汉、战略性摆烂、阴间战神等稀有称号，解锁不可逆|
|🔔 **DDL 推送提醒**|任务到期前 6h / 1h 自动推送（即使 App 关闭），点击直跳任务详情|
|📊 **数据统计**|今日活动饼图、本周 / 本月分组柱图、累计统计、每日明细|
|🔒 **反作弊系统**|4h 单次上限、12h 累计锁定、惩罚性删除、过期任务只读、时光倒流防御（HC-01 ~ HC-08）|
|❓ **关于页面**|版本信息、功能清单、更新日志、开发者彩蛋（10 次快速点击解锁 Debug 后门）|

## 🚀 快速开始

### 环境要求

- Node.js ≥ 20
- pnpm ≥ 9
- Expo CLI（`pnpm install -g expo-cli`）
- iOS 模拟器（Xcode）或 Android 模拟器（Android Studio）

### 安装与运行

```bash
# 克隆项目
git clone <repo-url>
cd app-bmlmo7hbv9c1

# 安装依赖
pnpm install

# 启动 Metro 开发服务器
pnpm start

# 在 iOS 模拟器运行
pnpm ios

# 在 Android 模拟器运行
pnpm android
```

> 本项目为纯本地 SQLite 架构，**无需配置任何后端或环境变量**，克隆后即可直接运行。

## 📐 精神状态算法

### 生命值（HP，0–100）

```
HP = 80
   − (睡眠不足小时数 × 5)
   − (未完成 DDL 数量 × 8)
   − (摸鱼小时数 × 2)
   + (学习小时数 × 3)
```

### 理智值（SAN，0–100）

```
SAN = 80
    − (连续熬夜天数 × 8)
    − (红温 DDL 数量 × 12)
    − (摸鱼小时数 × 1.5)
```

### DDL 危险等级

|剩余时长|等级|颜色|
|---|---|---|
|> 48h|安全 🟢|`#39FF14`|
|24–48h|注意 🟡|`#FFD700`|
|12–24h|危险 🟠|`#FF8C00`|
|< 12h|红温 🔴|`#FF003C`|
|< 3h|濒死 💀|`#FF003C`|

## 🔒 反作弊系统（HC-01 ~ HC-08）

v2.2 引入 8 条硬性反作弊规则，保障核心数值循环的工程级健壮性：

|编号|规则|实现位置|
|---|---|---|
|HC-01|单次计时会话 **4h 硬上限**，超出直接作废|`slack.tsx`|
|HC-02|当日异常计时累计 **12h 即锁定**计时器|`db/api.ts`|
|HC-03|删除任务扣 Karma −10 / HP −5（**惩罚性删除**）|`ddl.tsx`|
|HC-04|已过期任务进入**只读模式**，无法编辑或伪造完成时间|`ddl.tsx`|
|HC-05|每日结算**懒惰结算**（进入相关页面时按需触发），24h 分钟上限钳制|`db/api.ts`|
|HC-06|成就解锁**不可逆**，任何数值下降不会撤销已获得成就|`achievements.ts`|
|HC-07|每日累计分钟数上限 **1440min（24h）**，防止手动输入刷数据|`db/api.ts`|
|HC-08|**时光倒流防御**：检测系统时间回退（容差 60s），检测到后弹窗警告 + 封印计时器写入|`slack.tsx` +`db/api.ts`|

### HC-08 时光倒流防御详解

- **检测机制**：每次进入摸鱼页时，读取 AsyncStorage 中的「上次可信时间戳」，若`当前时间 < 上次记录 − 60s` 即判定为时光倒流。
- **触发效果**：① 弹出粉色警告弹窗 ② 顶部显示封印横幅 ③ 禁用开始学习 / 开始摸鱼按钮 ④`stopTimer()` 写入数据库前被拦截。
- **自动恢复**：将系统时间修正为正确值后，重新进入摸鱼页，检测通过即自动解除封印。
