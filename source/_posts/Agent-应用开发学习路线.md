## Agent 应用开发学习路线

## 第一部分：技术栈必学清单

针对你目前的基础，主线建议定为：

**Python 工程开发 → HTTP／FastAPI → 数据库 → 异步与任务管理 → Agent／MCP → RAG → 测试评测 → 部署。**

下面只列技术和具体知识点。优先级含义：

- **P0：优先掌握，作为 Agent 应用开发实习的基础。**
- **P1：之后补充；目标岗位明确要求时提前。**
- **P2：专项技术，按岗位选择。**

不是所有条目都需要达到同样深度，也不需要全部学完才投递。

---

**1．Python 语言基础与工程写法【P0】**

你已经会刷题，重点补下面这些：

- **对象与变量**：对象引用、可变与不可变对象、赋值与复制、浅拷贝与深拷贝、`==` 与`is`。
- **容器**：`list`、`tuple`、`dict`、`set`，哈希与可哈希对象，常见操作复杂度。
- **函数参数**：位置参数、关键字参数、默认参数、可变默认参数陷阱、`*args`、`**kwargs`。
- **作用域**：局部变量、全局变量、闭包、`global`、`nonlocal`、延迟绑定。
- **函数式用法**：函数作为参数、回调、装饰器、`functools.wraps`。
- **面向对象**：类与实例、实例属性与类属性、继承、组合、`super()`、类方法、静态方法。
- **常用特殊方法**：`__init__`、`__repr__`、`__str__`、`__call__`、`__iter__`。
- **数据对象**：`dataclass`、`Enum`。
- **类型标注**：`list[T]`、`dict[K, V]`、联合类型、可空类型、`Callable`、`TypedDict`；`Protocol` 和泛型后续补。
- **异常处理**：异常分类、自定义异常、异常链、`try/except/else/finally`、异常传播。
- **资源管理**：`with`、上下文管理器、文件与连接释放。
- **迭代机制**：迭代器、生成器、`yield`、惰性处理。
- **字符串与编码**：Unicode、UTF-8、`str` 与`bytes`、编码与解码。
- **序列化**：JSON、JSONL、Python 对象与 JSON 类型转换。
- **时间处理**：时间戳、时区、UTC、`datetime`、单调时钟与耗时统计。

常用标准库：

`pathlib`、`json`、`logging`、`datetime`、`time`、`argparse`、`collections`、`itertools`、`functools`、`re`、`enum`、`dataclasses`、`typing`。

**3．HTTP 与网络接口基础【P0】**

- **URL**：协议、域名、端口、路径、查询参数。
- **请求结构**：方法、请求头、请求体。
- **响应结构**：状态码、响应头、响应体。
- **HTTP 方法**：GET、POST、PUT、PATCH、DELETE、OPTIONS。
- **状态码**：200、201、202、204、400、401、403、404、409、422、429、500、502、503、504。
- **数据格式**：JSON、表单、multipart、文件上传。
- **常见请求头**：`Content-Type`、`Accept`、`Authorization`、`Retry-After`。
- **接口设计**：REST、资源命名、分页、过滤、排序、错误结构、接口版本。
- **幂等性**：重复提交、幂等键、重复执行与结果去重。
- **身份验证**：Cookie、Session、Bearer Token、JWT 基础。
- **权限控制**：认证与授权、资源归属、角色权限。
- **浏览器机制**：同源策略、CORS、预检请求。
- **网络链路**：DNS、TCP、TLS、HTTPS、连接复用。
- **接口调试**：curl、Apifox、浏览器 Network 面板。

🚀 入门基础：搭好地基

在开始编码前，需要先建立对大模型应用开发的整体认知。

核心概念： 了解什么是大模型、Transformer 架构、注意力机制等基本原理，但不用一开始就深究底层算法。
编程语言： 熟练掌握 Python，这是大模型领域的通用语言。
必备工具： 学会使用 Git 进行版本控制，了解 HTTP/JSON 接口的基本原理。

🛠️ 实战核心：掌握工具链

大模型应用开发有一套成熟的工具链，熟练掌握它们是求职的敲门砖。

应用框架： LangChain 和 LlamaIndex 是目前最主流的两个框架，强烈建议重点学习。跟着官方文档和教程，把核心功能（如多轮对话、工具调用、文档检索）跑通。
向量数据库： 用于存储和检索文本的向量表示，是构建RAG（检索增强生成）系统的关键。可以先从 Chroma、Milvus 或 Qdrant 中选一个开始学习。
服务部署： 学习用 FastAPI 或 Flask 将你的大模型应用封装成 API 服务，这是项目落地的必备技能。Docker 也是加分项。

💡 项目为王：打造你的作品集

光会跑 Demo 是不够的，面试官更看重你解决实际问题的能力。

复现开源项目： 在 GitHub 上找一些高星的 RAG 或 Agent 项目，尝试在本地跑通。过程中故意“捣乱”，比如调整参数、更换模型，看看会发生什么，这能帮你深入理解系统。
构建完整项目： 从一个简单的“企业知识库问答系统”或“合同解读机器人”开始，尝试完成从需求分析、数据处理、模型调用到服务部署的完整流程。
关注业务落地： 企业真正关心的是 AI 能否解决业务痛点。思考如何将你的技术方案与实际业务结合，比如设计用户交互流程、处理模型“幻觉”和错误兜底等。

📚 学习资源：高效进阶

系统课程： 吴恩达的《大模型应用开发实战》课、王树森的《大模型应用开发实战》、李沐团队的 HuggingFace 教程都是不错的选择。
实战教程： Datawhale 在 GitHub 上的开源项目（如 hello-llm、all-in-rag）非常适合动手实践。
社区与博客： GitHub、Hugging Face、LangChain 官方博客是获取最新实践和灵感的好地方。
B站UP主： 搜索“大模型实战录”、“LangChain学习小组”、“大模型图解君”等 UP 主，能找到很多保姆级的实操视频。
✨核心避坑指南

别只看不练： 大模型开发是“手艺人”活，光看视频没用，必须跟着教程一行一行地敲代码。
从项目出发： 不要追求学完所有理论再开始项目，边做项目边查缺补漏，效率更高。
目标是落地： 你的最终目标不是调用 API，而是解决一个真实的业务问题，这决定了你的价值。
